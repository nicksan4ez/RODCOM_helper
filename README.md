# Telegram-Бот Напоминаний Родкома

Компактный Telegram-бот для админского чата родительского комитета. MVP напоминает о днях рождения детей и учителя, учитывая выходные и праздничные дни РФ.

## Что делает бот

- Один раз импортирует стартовый список из `List.docx`, если база еще пустая.
- После первого импорта данные живут в SQLite: добавление, изменение и удаление выполняются командами бота.
- Каждый день в `07:30` по `Asia/Vladivostok` проверяет, нужно ли отправить напоминание.
- Если день рождения выпадает на выходной или праздник, выбирает первый рабочий день после выходных/праздников для поздравления.
- Напоминание отправляется за сутки до дня рождения; если эта дата нерабочая, переносится на ближайший предыдущий рабочий день.
- Хранит данные в SQLite внутри Docker volume.

## Настройка

1. Создайте бота через `@BotFather` и получите `BOT_TOKEN`.
2. Скопируйте `.env.example` в `.env`.
3. Заполните:
   - `BOT_TOKEN` — токен бота.
   - `ADMIN_CHAT_ID` — id админского чата.
   - `ADMIN_USER_IDS` — Telegram user id администраторов через запятую.
4. Запустите:

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f rodcom-bot
```

Остановка:

```bash
docker compose down
```

Данные сохраняются в volume `rodcom-data`.

`SOURCE_DOCX_PATH` нужен только для первого заполнения пустой базы. Если база уже создана в volume, бот при перезапуске не перечитывает DOCX и не затирает изменения, сделанные через команды.

## Команды

Основной интерфейс кнопочный. Напишите `/start`, затем выбирайте действие кнопками:

- `Ближайшие ДР` — показать 3 ближайших дня рождения.
- `Сегодня` — показать напоминания на сегодня.
- `Список` — открыть список класса с разделами `Учитель` и `Ученики`.
- `Настройки` — посмотреть время напоминаний и изменить его кнопкой `Изменить время`.
- Внутри `Списка` можно переключить сортировку чекбоксами: `По ФИО` или `По ДР`.
- Там же находятся кнопки управления списком:
  - `Ребенок` / `Учитель` — добавить запись; бот по шагам спросит ФИО, дату и примечание.
  - `Изменить` — бот покажет список, попросит номер записи и предложит кнопки `ФИО`, `Дата`, `Роль`, `Примечание`.
  - `Скрыть` — убрать человека из напоминаний без удаления.
  - `Вернуть` — снова включить скрытую запись.
  - `Удалить` — полностью удалить запись из базы; бот попросит подтверждение.

Технические команды также оставлены как быстрый способ для продвинутых пользователей:

- `/next`, `/month [1-12]`, `/today`, `/people`, `/settings`, `/test_reminder`.
- `/add ...`, `/edit ...`, `/disable ...`, `/restore ...`, `/delete ...`.

Если бот работает в групповом чате, для пошагового ввода текста удобнее отключить privacy mode у бота через `@BotFather` или отвечать reply-сообщением на вопросы бота. В личном чате с администратором пошаговый режим работает без дополнительных настроек.

## Производственный календарь

В коде есть фиксированные праздничные дни РФ и ручные переносы на 2026 год по постановлению Правительства РФ от 24.09.2025 N 1466. Переносы следующих лет нужно добавлять после публикации официального постановления.
